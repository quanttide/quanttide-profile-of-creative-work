# 量潮创意工作档案

收创意工作领域蒸馏出的稳定档案。

## 租户目录

内容按租户分一级目录：`quanttide-founder/` 收创始人个人的创意项目，`quanttide-tech/` 收量潮科技的创意项目——同一领域下不同主体的创意项目在此分隔，互不混放。

租户下按**工作区**分二级目录（英文标识）：`workplace-romance/`（职场言情）、`rebirth-romance/`（重生言情）——一部作品一个工作区，高频迭代与中间过程在各自工作区内留痕。工作区内再按素材类型分（`images/`、`videos/`）；租户顶层的 `images/`、`videos/` 为未分区素材。
