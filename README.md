# 量潮创意工作档案

收创意工作领域蒸馏出的稳定档案。

## 租户目录

内容按租户分一级目录：`quanttide-founder/` 收创始人个人的创意项目，`quanttide-tech/` 收量潮科技的创意项目——同一领域下不同主体的创意项目在此分隔，互不混放。

租户下按**工作区**分二级目录（英文标识）：`urban-romance/`（职场言情）、`rebirth-romance/`（重生言情）——一部作品一个工作区，高频迭代与中间过程在各自工作区内留痕。工作区内再按素材类型分（`scripts/`、`images/`、`videos/`）：小说原文改写成剧本（scripts/），图稿（images/）与拍卡（videos/）从剧本取用。

**编号命名规则**：`章_场_镜_名字`，三段编号对齐剧本（章＝剧本章序、场＝场号、镜＝场内镜号，镜号表在剧本场次里），名字取自剧本。一镜一档——成图、图稿、拍卡、成片同一规则；跨镜参考资料（如实拍参考）用场级 `章_场_名字`。编号只增不改：剧本往后加镜排新号，已有文件不重排。
